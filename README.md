# 頁面朗讀助手（Reader Extension）

Chrome MV3 瀏覽器擴充功能，朗讀網頁文字內容，支援快捷鍵暫停/播放、語速調整、朗讀片段高亮，以及從選取位置開始接續朗讀。

## 功能

- **朗讀網頁內容**：自動掃描頁面可見文字，依句尾符號（。！？.!? 等）切句後逐句朗讀（Web Speech API）。
- **空白鍵暫停/播放**：在頁面上按下空白鍵即可快速切換播放狀態；若焦點在輸入框、textarea 或 contentEditable 元素中則不會被攔截，不影響一般輸入。
- **語速調整**：以 `0.25` 為單位調整，範圍 `0.5x ~ 3.0x`，設定會透過 `chrome.storage.sync` 保存。
- **朗讀片段高亮**：目前朗讀中的句子會以 `background-color` 高亮顯示，顏色可在 popup 中透過色彩選擇器自訂並即時套用。
- **從選取處開始朗讀**：在頁面上選取一段文字後，透過右鍵選單「從選取處開始朗讀」或 popup 內的按鈕，會從該選取位置對應的句子開始朗讀，並自動往後接續朗讀後續內容。

## 安裝方式（開發者模式載入）

1. 開啟 Chrome，前往 `chrome://extensions`
2. 開啟右上角「開發人員模式」
3. 點擊「載入未封裝項目」
4. 選擇本專案的 `reader-extension` 資料夾

## 使用方式

- 點擊瀏覽器工具列上的插件圖示開啟 popup，按「▶ 播放」開始朗讀當前頁面。
- 頁面上按 `空白鍵` 可暫停/繼續朗讀。
- 在 popup 中用 `－0.25` / `＋0.25` 按鈕調整語速。
- 在 popup 中用顏色選擇器調整高亮背景色，即時套用到目前朗讀片段。
- 在頁面上選取任意一段文字後：
  - 右鍵選單點擊「從選取處開始朗讀」，或
  - 開啟 popup 點擊「從選取處開始朗讀」按鈕

  即可從該選取位置對應的句子開始朗讀，並自動往後接續朗讀。

## 檔案結構

```
reader-extension/
├── manifest.json     # MV3 設定，宣告 permissions、content script、background、popup
├── background.js     # Service worker：建立「從選取處開始朗讀」右鍵選單並轉發訊息
├── content.js         # 核心邏輯：文字掃描分句、Web Speech 朗讀、空白鍵監聽、高亮、選取定位
├── content.css        # 高亮片段樣式
├── popup.html/css/js  # 工具列彈出視窗 UI（播放/暫停/停止、語速、顏色、從選取處開始朗讀）
└── icons/              # 插件圖示（16/48/128px，目前為占位色塊，建議正式上架前更換）
```

## 已知限制

- 依賴瀏覽器內建 `SpeechSynthesis`，發音品質與可用語音因作業系統/瀏覽器而異。
- 不支援 `chrome://`、`edge://` 等瀏覽器內建頁面（權限限制）。
- 動態載入的內容（例如無限滾動載入的新文字）需重新觸發朗讀或選取才會被收錄進片段索引。
- 若頁面在朗讀過程中大幅重新渲染 DOM，可能需要重新選取一次以重建片段索引；程式已在偵測到節點失效時自動重建索引並嘗試以文字內容找回原本位置。

## 權限說明

| 權限 | 用途 |
| --- | --- |
| `activeTab` | 讀取並操作目前分頁的內容以進行朗讀與高亮 |
| `scripting` | 保留給未來以程式化方式注入內容腳本使用 |
| `storage` | 保存語速、高亮顏色等使用者設定 |
| `contextMenus` | 提供「從選取處開始朗讀」右鍵選單項目 |

本插件不會發送任何網路請求，也不會收集或上傳使用者資料。
